# Concept — EU CO2 transport si storage hubs

**EN:** European CO₂ transport and storage infrastructure · **RO:** infrastructura europeană de transport și stocare CO₂

Cross-border network required to connect dispersed biogenic point-sources and DACCS hubs to geological storage.

Parent: [[Concept — CDR integrare EU ETS post-2030]] · technology: [[Concept — DACCS vs BioCCS economics]]

**EU target:** Net-Zero Industry Act — **≥50 Mt/year** operational CO₂ injection capacity by **2030**.

## North–South divide

```
                    EUROPEAN CO₂ STORAGE

           ┌───────────────┴───────────────┐
           ▼                               ▼
    NORTH SEA BASIN                  MEDITERRANEAN
    (mature · Phase 1)               (emerging · Phase 2)
```

### North Sea (operational baseline)

| Project | Capacity / status | Notes |
|---|---|---|
| **Northern Lights** (Norway) | 1.5 Mtpa Phase 1 operational → >5 Mtpa Phase 2 | Equinor/Shell/TotalEnergies · Aurora reservoir · LCO₂ vessels |
| **Porthos** (Netherlands) | Rotterdam port cluster → offshore fields | Pipeline from port industrial zone |
| **Aramis** (Netherlands) | Open-access for inland emitters | River barges + trunk pipelines |
| **Greensand** (Denmark) | Cross-border shipping + offshore injection | Depleted sandstone reservoirs |

### Mediterranean (emerging corridor)

| Project | Focus |
|---|---|

| **Prinos** (Greece) | 1 Mtpa Phase 1 → ~2.8–3 Mtpa · SE European hub |
| **Pycasso / Pyrénées** (France/Spain) | SW Europe cross-border formations |

## DACCS vs BioCCS infrastructure paths

```
BioCCS:  [Inland flue gas] → rail/barge → coastal terminal → offshore aquifer
DACCS:   [Atmospheric capture] → co-located over storage (bypasses long transport)
```

| Dimension | BioCCS | DACCS |
|---|---|---|
| Geographic dispersion | Fragmented (Nordics, inland WtE) | Flexible — site over storage or clean power |
| Primary transport | Multimodal: barge, rail, feeder pipeline | Local pipeline / direct wellhead injection |
| Purity | On-site liquefaction + amine cleanup needed | >99% CO₂ from desorption |
| Bottleneck | Port cryogenic buffer tanks | GW-scale clean power interconnection |

---

## Structural bottlenecks

| Bottleneck | Risk |
|---|---|
| **LCO₂ carrier shortage** | Semi-refrigerated vessels (~15 bar, −30°C) — global shipyard backlog |
| **London Protocol Art. 6** | Cross-border CO₂ export needs bilateral agreements — delays in S/E Europe |
| **Inland pipeline "last mile"** | e.g. Delta Rhine Corridor — stranded inland emitters without state-backed trunklines |
| **Storage hub monopoly pricing** | Limited geological sites → need open-access tariff regulation |

---

## Romania relevance

No domestic geological CO₂ storage identified at scale — Romanian BioCCS/DACCS projects would depend on **maritime transport** to North Sea or Mediterranean hubs and applicable London Protocol bilateral frameworks.

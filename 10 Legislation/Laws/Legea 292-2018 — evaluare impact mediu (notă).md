# Legea 292/2018 — evaluarea impactului asupra mediului — Analysis

**Raw text:** [[Legea 292-2018 — evaluare impact mediu (text)]] · **Umbrella:** [[OUG 195-2005 — protectia mediului (notă)|OUG 195/2005]] · **Concept:** [[Concept — Acord de mediu si AIM]] · **DD:** [[_Energy Investment Due Diligence Index]]

## Thesis

Special EIA statute implementing the EU EIA Directive path: **screening → assessment → public consultation → *acord de mediu***. Read together with OUG 195 principles and the AIM/operate authorisation tier — *acord* is not AIM.

## Architecture

Screening / Annex project lists · EIA report contents · public consultation · *acord de mediu* decision · authority competences (APM / MMAP) · interface with building permit.

## Operative regime (energy)

1. Classify project (RES / BESS / lines) for screening vs mandatory EIA.
2. Run consultation diligently — defects are the usual NGO annulment vector.
3. Obtain *acord de mediu* before building permit; AIM/authorisation before operate ([[Concept — Acord de mediu si AIM]]).
4. Cross-check acceleration overlays in [[OUG 163-2022 — promovare energie regenerabila (notă)|OUG 163]].
